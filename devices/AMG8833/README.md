## 概要

センサから見て上下左右のおよそ 60 度の範囲を 8x8 ピクセルに分割し、それぞれのエリアについて 0℃ ～ 80℃ の範囲で測定可能なサーモグラフィです

## インターフェース

I2C

## 使用パッケージ

- `@chirimen/amg8833`
